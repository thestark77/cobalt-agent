# Attribution

Skill: `design-taste-frontend`

This skill encodes anti-slop frontend design principles for landing pages,
portfolios, and redesigns. It was developed as a companion to
[gpt-tasteskill](https://skills.sh/Leonxlnx/taste-skill/gpt-tasteskill) and
draws on real production-test patterns collected from LLM-generated landing
page reviews.

This file is bundled with cobalt-agent for offline use.
